## Agent skills

Track issues in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels
Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs
Use a single-context layout. See `docs/agents/domain.md`.

### Project contract and acceptance
Before changing pipeline behavior, read `docs/project_spec.md` and the relevant task in `docs/implementation_plan.md`.
Use `docs/test_acceptance_matrix.md` for required evidence. The user accepts tasks after reviewing outputs, test cases, and outcomes; passing checks alone does not authorize acceptance or dependent task execution.
